# Lessons Learned

This lab improved my understanding of how SQL Injection vulnerabilities occur and why secure handling of user input is important.

## Key Lessons

Through this project, I learned:

- How user input can affect database queries.
- Why input validation alone may not fully prevent SQL Injection.
- Why parameterised queries and prepared statements are important.
- How insecure error messages can disclose technical information.
- How to document a vulnerability using explanations and screenshots.
- How to describe the potential business and security impact of a vulnerability.
- How to recommend practical remediation measures.
- Why security testing must only be conducted with proper authorisation.

## Skills Developed

The project helped me develop skills in:

- Web application security
- Vulnerability identification
- Security risk analysis
- Evidence collection
- Technical report writing
- Remediation planning
- GitHub project documentation

## Personal Reflection

The project showed me that a small weakness in how an application processes input can create a serious security risk. It also helped me understand that identifying a vulnerability is only one part of security work. A security professional must also document the issue clearly, explain the impact, preserve evidence, and recommend practical controls.

This project strengthened my interest in defensive cybersecurity, vulnerability management, and Security Operations.
