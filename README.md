# SQL Injection Lab Write-Up

## Project Overview

This repository contains my SQL Injection lab write-up completed in a controlled training environment. The project demonstrates how SQL Injection vulnerabilities can affect a web application when user input is not properly validated or handled securely.

The lab focused on identifying vulnerable input fields, observing how SQL queries respond to manipulated input, documenting the findings, and recommending appropriate security controls.

## Objectives

The objectives of this project were to:

- Understand how SQL Injection vulnerabilities occur.
- Identify potentially vulnerable input fields.
- Test input in a controlled lab environment.
- Document the results using written explanations and screenshots.
- Explain the security impact of SQL Injection.
- Recommend appropriate remediation measures.
- Reflect on the lessons learned during the lab.

## Repository Structure

- `README.md`: Overview of the project.
- `findings.md`: Main vulnerabilities and observations identified during the lab.

## Key Security Concepts

The project demonstrates the importance of:

- Parameterised queries
- Prepared statements
- Server-side input validation
- Secure error handling
- Least-privilege database permissions
- Regular security testing
- Secure coding practices
